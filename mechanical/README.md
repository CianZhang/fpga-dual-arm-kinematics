# 机械结构补充设计

两套机械臂以网络公开的 STL 方案为基础，项目作者在此基础上自行建模并补充部分结构。作者确认：原资料中的 STL 属于网络参考材料，SolidWorks 源文件为本人建模。本仓库据此收录 `.SLDPRT` 与 `.SLDASM`，不把整体机构方案声明为独立原创。

`solidworks/` 保留原建模目录层级，以减少装配相对引用变化。建模归属并不表示每个零件的机构原理或外形都是首次设计；个人贡献应表述为基于现有方案的建模与结构补充。

| 原目录 | 整理方式 |
| --- | --- |
| Delta建模 | 收录其中的 SolidWorks 源文件，包含配套支架、安装件与结构件 |
| 2022delta | 收录 SolidWorks 源文件；目录名保留为来源标识，不据此判定制作年份或最终版本 |
| 带滑轨的步进电机机械臂 | 收录其中的 SolidWorks 源文件，例如泵托与泵托盖 |
| 网络 STL | 只记录清单和来源线索，不随仓库重新分发 |
| 3MF 等其他格式 | 留在原资料中，清单注明未纳入 |

[浏览 96 个 SolidWorks 文件索引](parts-index.md)。

全部机械文件清单见 [source-inventory.json](source-inventory.json)，实际收录文件见 [solidworks](solidworks/)。原 STL 来源线索见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

未在本次整理中使用 SolidWorks 打开 / 重建装配，也未生成 STEP。由于外部 STL 和可能存在的外部装配依赖未随仓库分发，装配打开后的缺失引用需要在 CAD 软件内核对。报告中的装配截图用于浏览展示，不代表已完成装配文件完整性验证。
