# 逆运动学与坐标约定

## Delta 机械臂

原模型中 m、n 分别为主动臂与从动臂长度，R、r 分别为静平台与动平台半径。令 d=r−R，三个分支对应的系数为：

```text
A1 = 2m(d+x)
B1 = -2mz
C1 = (d+x)² + y² + z² + m² - n²

A2 = 2m(d-x/2+√3·y/2)
B2 = -2mz
C2 = (d-x/2+√3·y/2)² + (√3·x/2+y/2)² + z² + m² - n²

A3 = 2m(d-x/2-√3·y/2)
B3 = -2mz
C3 = (d-x/2-√3·y/2)² + (√3·x/2-y/2)² + z² + m² - n²
```

这些系数进入 `A sin(θ) + B cos(θ) = C` 的求解。原脚本使用 √3/2≈0.8660；整理新增的 Python 入口默认沿用该近似，便于对照原脚本。

原实现选择的计算分支：

```text
D = A² + B² - C²
N = -A·B - C·sqrt(D)
Q = A² - C²
θ = atan(N/Q)，按原程序规则调整至所需角度分支
电机命令角 = 130° - θ
```

`reference/delta_inverse.py` 返回原模型相同分支下的电机命令角。它会拒绝负判别式和零分母；并未加入完整碰撞检测、机械限位或所有奇异情况的替代解，不能直接充当任意机器人通用逆解库。

报告对比点的物理坐标为 `(0, 0, -237.5)` mm，RTL 输入编码为 `(0, 0, -3800)`。不要把编码值直接当成毫米。

## 连杆机械臂

`arm_motion_solver.v` 先处理空间坐标：旋转轴由 XY 投影求角，大小臂使用平面距离与高度求解。`solver_rotation.v` 含旋转方向选择，`solver_big_and_small_arm.v` 包含连杆长度、末端偏移与角度处理。平移轴由上层控制与对应电机模块处理，不能把三关节解算模块等同于完整四轴规划器。
