# 贡献与来源

| 内容 | 仓库处理 |

## 机械模型的来源边界

作者已确认：两套机械臂以网络 STL 方案为基础，本人补充了一部分结构；资料中的 STL 是网络参考材料，SolidWorks 源文件为本人建模。因此仓库机械贡献表述为“基于现有 STL 方案的结构补充设计与 SolidWorks 建模”，不称为两套机构完全从零原创。

`mechanical/solidworks/` 收录 SolidWorks 源文件并保留原目录名。外部 STL 只列来源清单，不随本仓库分发。3MF 等其他格式保留在原资料中。

原 `建模/readme.txt` 的两个 Thingiverse 链接和 Bilibili 教程是参考来源线索，尚未逐个对应到每个零件。整体方案来源与本人源文件归属分别说明，不用文件扩展名推断机构方案原创性。
